Task B - Relational Schema Diagram

Every relation below is the relational mapping of the E-R model. PK attributes are underlined. Arrows point from foreign keys to the referenced primary-key relation; composite foreign keys are called out explicitly.

Underlined row primary key PK, FK both key types Arrow FK to referenced PK Composite PK ternary contribution identifier Composite FK aggregation target Partial key weak-entity citation year
Important mapping decisions: `publication_count` is derived and therefore absent from the schema; `full_name` is represented by `first_name` and `last_name`; the weak citation record uses `(publication_id, citation_year)`; the aggregate review references one exact `(researcher_id, publication_id, research_area_id)` contribution occurrence; and the restored `PUBLICATION_TOPIC(publication_id, research_area_id, source, relevance_score)` and `PUBLICATION_AUTHOR(publication_id, author_order, researcher_id, author_name, author_orcid, openalex_author_id, is_corresponding)` relations preserve paper-level discovery data without inventing researcher-topic combinations.
