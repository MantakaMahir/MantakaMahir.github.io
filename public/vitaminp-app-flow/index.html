Readable flow

First-time setup

Start → no saved pairing → Welcome → permission explanation → Bluetooth permission → scan and pair → confirm connection → Wear Guidance → Calibration → device confirms completion → Home: Live Posture.

Permission denied: help / open settings → retry. Pendant not found or connection failed: scan again / troubleshooting. Incorrect placement or calibration failure: guidance → retry.

Returning user and reconnection

App opens → saved pairing recognized → check Bluetooth connection → connected → Home. Saved pairing alone never enables live posture; valid calibration is also required.

Connection unavailable or lost → retain pairing → show disconnected status and unavailable live posture/current battery → show last sync → reconnect → confirm connection → Home. Failure → retry / troubleshooting.

Posture, wellness and device management

Home centers on Live Posture, upright feedback and gentle adjustment prompts. Pendant haptic triggers, patterns and delays follow Mushfique’s firmware definition.

  • History: daily posture timeline, upright-time progress and weekly trends.
  • Wellness / Activity: Heart Rate, SpO₂ and Steps / Activity, secondary to posture.
  • Device: saved pairing, live Bluetooth connection, battery/charging and pendant-to-phone sync; recalibration, troubleshooting and unpairing.
  • Settings: firmware-dependent haptic controls and proposed Quiet Hours. Recalibration returns to Calibration.
Friends / Connections — future, inactive in Stage 1

This flow is separate from Bluetooth device pairing. Accounts/backend and consent are needed before sharing becomes available.

  1. Add or invite a friend.
  2. Accept the connection.
  3. Select what to share: Posture progress, Steps / Activity, Heart Rate and SpO₂.
  4. View shared progress.
  5. Change or pause sharing choices.
  6. Remove the friend / revoke access.
Design flow only. Device readings and exact behavior depend on hardware/firmware integration.
